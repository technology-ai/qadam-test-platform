# PRD: Система тестирования сотрудников Казахтелеком

## 1. Цель продукта

Создать веб-приложение для обучения и проверки знаний сотрудников Казахтелеком по двум направлениям: БиОТ и техническая часть. Доступ к тестированию предоставляется только авторизованным пользователям.

## 2. Роли пользователей

- **Сотрудник** — проходит тесты и просматривает свои результаты.
- **Администратор** — управляет пользователями, вопросами, тестовыми базами и проходным баллом, просматривает результаты сотрудников.

## 3. Авторизация

При первом открытии приложения пользователь видит только страницу входа.

- Поля: «Логин» и «Пароль».
- Кнопка «Войти».
- Проверка пустых и неверных данных.
- Доступ к тестам предоставляется только после успешной авторизации.
- Пароли должны храниться в виде хеша.
- Пользовательская сессия должна быть защищена.

## 4. Личный кабинет

После входа сотруднику доступен личный кабинет с двумя базами тестов:

1. «БиОТ» — безопасность и охрана труда.
2. «Техническая часть Казахтелеком».

## 5. Прохождение теста

- Каждый тест состоит ровно из 50 вопросов.
- При каждом новом прохождении вопросы случайно выбираются из соответствующей базы.
- Порядок вопросов и вариантов ответов перемешивается.
- Вопрос может иметь один или несколько правильных вариантов ответа.
- Интерфейс показывает номер вопроса, прогресс и навигацию между вопросами.
- Ответы пользователя сохраняются до завершения или закрытия теста.

## 6. Результаты

После отправки теста система автоматически подсчитывает результат.

- При успешной сдаче выводится сообщение: «Отлично! Тест успешно сдан».
- При неуспешной сдаче выводится сообщение: «Тест не сдан. Повторите попытку».
- Проходной процент должен настраиваться администратором.
- Для каждой попытки сохраняются дата, база тестов, число правильных ответов, итоговый результат и статус «сдан» или «не сдан».

## 7. Повторное прохождение

- Перед повторной попыткой система сообщает: «Вы проходите тест второй раз».
- Для третьей и последующих попыток указывается актуальный номер: например, «Вы проходите тест 3-й раз».
- Каждая новая попытка использует новый случайный набор из 50 вопросов.

## 8. Закрытие теста

При нажатии «Закрыть тест», выходе из теста или попытке закрыть страницу выводится модальное окно:

> Действительно хотите закрыть тест? Несохранённые ответы могут быть потеряны.

Доступные действия:

- «Да, закрыть» — завершить или зафиксировать попытку как незавершённую.
- «Нет, продолжить тест» — вернуться к прохождению.

## 9. Панель администратора

Администратор может:

- управлять пользователями;
- добавлять, изменять и удалять вопросы;
- относить вопросы к категориям «БиОТ» и «Техническая часть Казахтелеком»;
- настраивать проходной балл;
- просматривать результаты и историю попыток сотрудников.

## 10. Данные и интерфейс

Необходимые сущности базы данных:

- пользователи;
- вопросы;
- варианты ответов;
- попытки тестирования;
- ответы пользователей.

Интерфейс должен быть современным, понятным, адаптивным и полностью русскоязычным.
